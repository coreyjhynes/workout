# BUILD Training Tracker

Six-week upper body muscle-building block: **November 3 – December 14, 2026**. Day 1 is Tuesday, November 3.

## Publish

Go to **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then Save.

Once GitHub Pages has deployed, open https://coreyjhynes.github.io/workout/ on your phone in Chrome, choose **Add to Home screen** (or Install app).

## Use

Open **Today**, log each set's weight and reps, and mark it done. Cardio and measurements are tracked as well. Workout dates follow the six-week schedule from Nov 3. Progress is saved in the browser's local storage (no cross-device sync). Export JSON backup periodically and retain it somewhere safe. Import replaces your saved logs.

Overhead exercises require clearance following cervical surgery.
